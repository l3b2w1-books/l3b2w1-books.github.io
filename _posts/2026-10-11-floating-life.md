# 《浮生六记》

> 作者：沈复（字三白，号梅逸）｜清代自传体散文｜成书于嘉庆十三年（1808） 

## 一、书籍信息与版本源流

#### 作者

| 项目 | 内容                                               |
| -- | ------------------------------------------------ |
| 姓名 | 沈复，字三白，号梅逸                                       |
| 生卒 | 清乾隆二十八年（1763）生于长洲（今江苏苏州），卒年不详，约在 1825 年之后        |
| 身份 | 幕僚、商人、书画家、书贾。一生未入仕                               |
| 自述 | "余生乾隆癸未冬十一月二十有二日，正值太平盛世，且在衣冠之家，后苏州沧浪亭畔，天之厚我可谓至矣" |

#### 成书

书名"浮生"典出李白《春夜宴从弟桃李园序》——"而浮生若梦，为欢几何？"李白写兄弟之情，沈复写夫妻之情，同一"天伦之乐"的对象而侧重不同。

沈复 46 岁那年（嘉庆十三年，1808）随使团出使琉球，在琉球四个半月期间回忆往事，有感于苏东坡"事如春梦了无痕，苟不记之笔墨，未免有辜彼苍之厚"，乃作此书。原书六卷，约四万五千字。

#### 发现与刊行（一段传奇的接受史）

| 年份           | 事件                                                               |
| ------------ | ---------------------------------------------------------------- |
| 1847（道光二十七年） | 王韬的妻兄**杨引传**在**苏州冷摊**上发现残稿四卷，同年交给王韬                              |
| 1849         | 王韬感于书中夫妻之情与人生无常，为之写跋                                             |
| 1877（光绪三年）   | 杨引传将书稿交上海尊闻阁主人蔡尔康，刊入《独悟庵丛钞》——**最早刊本**                            |
| 1906         | 东吴大学《雁来红丛报》转载                                                    |
| 1915         | 王文濡辑入《说库》，此后坊间印本甚多                                               |
| 1924         | 北京霜枫社刊印，朴社发行，后改上海开明书店刊印                                          |
| 1936         | **林语堂英译**《Six Chapters of a Floating Life》，序言称陈芸"是中国文学上一个最可爱的女人" |

**关键**：成书之后至 1847 年间，此书**未曾刊刻，仅以稿本和抄本传世**，默默无闻近四十年。它的经典地位是近现代才确立的。

#### 存佚与伪作

原书六卷，**现存四卷**。卷五《中山记历》、卷六《养生记道》**仅有存目，内容已佚**。  
民国时期有人伪造此二篇，凑成所谓的"足本"《浮生六记》（2008 年有学者称发现卷五佚文，仍未能证实为沈复所著）。

## 二、全书结构总览

| 卷 | 卷名   | 时间跨度                          | 主题            |
| - | ---- | ----------------------------- | ------------- |
| 一 | 闺房记乐 | 幼年 → 乾隆六十年（1795）              | 夫妻之情的萌生与极盛    |
| 二 | 闲情记趣 | 主要为乾隆五十七至五十八年（1792–93）寄居萧爽楼时期 | 贫困中的生活美学      |
| 三 | 坎坷记愁 | 乾隆五十年（1785）→ 嘉庆十年（1805）       | 家庭压迫、两次被逐、芸之死 |
| 四 | 浪游记快 | 乾隆四十二年（1777）→ 嘉庆十一年（1806）     | 游幕三十年的山水行迹    |
| 五 | 中山记历 | （佚）                           | 出使琉球见闻        |
| 六 | 养生记道 | （佚）                           | —             |

**结构手法**：各卷按内容分类，主题明确，每卷内部依时间推进，各卷之间大致按时间先后排列。  
叙事头绪虽繁，但**始终以陈芸为中心，围绕"情""趣"二字展开**。  

内容有重复处则学《史记》互见法，此简彼详——如卷一提到"寄居萧爽楼"，其详情补于卷二；  
卷一以"后憨为有力者夺去，不果。芸竟以之死"作结，憨园负情、芸血疾大发诸事则补叙于卷三。


## 三、分卷

#### 卷一 闺房记乐

从幼年写起，至乾隆六十年（1795）陈芸与憨园结盟为止。核心是**一段以爱情为基础的婚姻**。

**缔姻**：沈复十三岁随母归宁，读到陈芸诗作，"虽叹其才思隽秀，窃恐其福泽不深，然心注不能释"，向母亲明言"若为儿择妇，非淑姊不娶"。母亦爱其柔和，即脱金约指缔姻（乾隆乙未，1775）。这是**摆脱"父母之命、媒妁之言"模式的自主选择**。

**陈芸其人**：舅氏心余先生女，字淑珍，与沈复同齿而长十月。生而颖慧，学语时口授《琵琶行》即能成诵；四龄失怙，家徒壁立，娴女红，"三口仰其十指供给"；后于书簏中得《琵琶行》，挨字而认始识字，渐通吟咏，有"秋侵人影瘦，霜染菊花肥"之句。沈复写其形貌不避缺陷——"削肩长项，瘦不露骨，眉弯目秀，顾盼神飞，**唯两齿微露，似非佳相**"。

**一系列成为经典的片段**：

| 片段       | 内容                                                                               |
| -------- | -------------------------------------------------------------------------------- |
| **藏粥**   | 夜半沈复腹饥，芸暗藏暖粥小菜于室，被堂兄玉衡撞破嘲之，遂传为话柄                                                 |
| **花烛**   | 乾隆庚子（1780）正月二十二日。合卺后并肩夜膳，"暗于案下握其腕，暖尖滑腻，胸中不觉抨抨作跳"                                 |
| **论诗**   | 芸独取李白而非杜甫："杜诗锤炼精纯，李诗激洒落拓……李诗宛如姑射仙子，有一种落花流水之趣。"沈复字三白，芸以太白为知己、乐天为启蒙师，戏言"与'白'字何其有缘" |
| **论礼**   | 芸迂拘多礼，沈复厌之曰"礼多必诈"；芸正色"世间反目多由戏起"。自此"岂敢""得罪"竟成语助词                                  |
| **七夕**   | 于我取轩同拜天孙，沈复镌"愿生生世世为夫妇"图章二方，沈执朱文、芸执白文                                             |
| **鬼节**   | 芸曰"妾能与君白头偕老，月轮当出"。论佛手为"香中君子"、茉莉为"香中小人"。桥下溺鬼惊魂，芸寒热大作——"乐极灾生，亦是白头不终之兆"             |
| **女扮男装** | 芸欲观水仙庙"花照"，易鬓为辫、加沈复冠、服其衣、着蝴蝶履，遍游庙中无人识破，后误按少妇之肩而被识破，"脱帽翘足示之曰：我亦女子耳"               |
| **太湖之游** | 托言归宁，随夫赴吴江吊丧。万年桥下待月乘凉，与船家女素云射覆行令。芸曰："此即所谓太湖耶？今得见天地之宽，不虚此生矣！想闺中人有终身不能见此者！"        |
| **卜居之愿** | 居金母桥老妪处避暑，芸曰："他年当与君卜筑于此，买绕屋菜园十亩……君画我绣，以为持酒之需。**布衣菜饭，可乐终身，不必作远游计也**"              |
| **绘月老像** | 倩苕溪戚柳堤绘月下老人像，石琢堂题赞，每逢朔望焚香拜祷。后因家庭多故遗失                                             |

**憨园之结**：芸主动为丈夫物色"美而韵者"，于虎丘得浙妓温冷香之女憨园（"一泓秋水照人寒"），与之结为姊妹并赠翡翠钏，欲效李笠翁《怜香伴》。卷一以八字收束全卷，也是全书命运的转折——

> "后憨为有力者夺去，不果。**芸竟以之死。**"

#### 卷二 闲情记趣

**中国语文教材中的名篇《童趣》（又题《幼时记趣》）即出自此卷**：

> 余忆童稚时，能张目对日，明察秋毫……夏蚊成雷，私拟作群鹤舞空……又留蚊于素帐中，徐喷以烟，使其冲烟飞鸣，作青云白鹤观……于土墙凹凸处、花台小草丛杂处，常蹲其身，使与台齐……以丛草为林，以虫蚁为兽，以土砾凸者为丘，凹者为堑，神游其中，怡然自得。

其余为一套完整的**贫士生活美学**：

- **插花法**：数宜单不宜双；每瓶取一种不取二色；瓶口取阔大不取窄小；"起把宜紧""瓶口宜清"；一桌三瓶至七瓶而止，多则"眉目不分"。
- **盆景法**：根露鸡爪者方可；"枝忌对节如肩臂，节忌臃肿如鹤膝"；一树剪成至少得三四十年。
- **叠石理园**：大中见小、小中见大、虚中有实、实中有虚——"不仅在'周回曲折'四字，又不在地广石多徒烦工费"。
- **静室焚香**：沉速等香于饭镢蒸透，铜丝架离火中寸许徐徐烘之，"其香幽韵而无烟"。
- **草虫法**（芸创）：觅螳螂蝉蝶，"以针刺死，用细丝扣虫项系花草间，整其足……宛然如生"。
- **活花屏法**：以竹编方眼插于木框，砂盆种扁豆盘延屏上，"恍如绿阴满窗，透风蔽日"。
- **梅花盒**：二寸白磁深碟六只，中一外五，灰漆就其形如梅花，"置之案头，如一朵墨梅覆桌"。
- **荷花茶**：荷花初开时晚含而晓放，芸用小纱囊撮茶叶置花心，明早取出，烹天泉水泡之，"香韵尤绝"。
- **南园之游**：菜花黄时苦无酒家小饮，芸雇市中馄饨担携炉火而往，"游人见之莫不羡为奇想"，众人叹曰"非夫人之力不及此"。
- **就事论事**：芸提出省俭之法，白纸糊壁使暗楼生亮，截旧竹帘代栏杆。

**萧爽楼**（友人鲁半舫家）——沈复一生最舒展的时期：

- **四忌**：谈官宦升迁、公廨时事、八股时文、看牌掷色，有犯必罚酒五斤。
- **四取**：慷慨豪爽、风流蕴藉、落拓不羁、澄静缄默。
- 杨补凡为夫妇写载花小影；王星澜月下就兰影以墨浓淡图之。

卷末一句，是全书最沉痛的对照：

> "今则天各一方，风流云散，兼之玉碎香埋，不堪回首矣！"

#### 卷三 坎坷记愁

从乾隆五十年（1785）新婚离别起，至嘉庆十年（1805）入石琢堂幕止。**全书的悲剧核心。**

开篇即设问："人生坎坷何为乎来哉？往往皆自作孽耳，**余则非也，多情重诺，爽直不羁，转因之为累**。"

**两次被逐**：

1. **第一次（壬子，1792）**：芸代笔家书，母疑其"述事不当"而止；父见信非芸手笔，怒曰"想汝妇不屑代笔耳"。芸宁可受责也不自辩："**宁受责于翁，勿失欢于姑也。**"此后庚戌年受托物色姚氏女，托言不当，吾母见之曰"此邻女之嬉游者也，何娶之乎"，芸**并失爱于姑**。壬子年启堂借债倩芸作保，芸致夫书信被父拆视，信中称"令堂""老人"，父怒斥"汝妇背夫借债，谗谤小叔……悖谬之甚"，遂遭逐出，寄居萧爽楼。两年后父知始末，骨肉重圆。
2. **第二次（庚申，1800）**：憨园被有力者以千金夺去，芸血疾大发；贫病交加，沈复为友人作保而友挟资远遁，放利债的西人咆哮于门；父怒曰"汝妇不守闺训，结盟娼妓……姑宽三日限"。芸于腊月二十五夜扶病遁往锡山华氏。

**临行一幕**（全书最动人的段落之一）：

> 芸强颜笑曰："**昔一粥而聚，今一粥而散，若作传奇，可名《吃粥记》矣。**"  
> 将交五鼓……逢森忽大哭曰："噫，我母不归矣！"……当是时，余两人寸肠已断，不能复作一语，但止以"勿哭"而已。  
> 解维后，芸始放声痛哭。**是行也，其母子已成永诀矣！**

**芸之死**（嘉庆癸亥，1803 年三月三十日）：临终遗言"妾死则亲心自可挽回，君亦可免牵挂……愿君另续德容兼备者，以奉双亲，抚我遗子"。沈复答："卿果中道相舍，断无再续之理，况'**曾经沧海难为水，除却巫山不是云**'耳。"芸执其手，仅断续叠言"**来世**"二字而逝。

沈复的自责与总结：

> "芸一女流，具男子之襟怀才识……**奉劝世间夫妇，固不可彼此相仇，亦不可过于情笃。语云'恩爱夫妻不到头'，如余者，可作前车之鉴也。**"

**后续变故**：芸权葬扬州金桂山，沈复自号梅逸。甲子（1804）父丧奔归，弟启堂唆使债主"乘凶追呼"，沈复答"**大丈夫贵乎自立，我既一身归，仍以一身去耳**"。赖友人夏淡安、夏揖山昆季相助，居大悲阁。乙丑（1805）随总角之交石琢堂赴四川重庆。丙寅（1806）闻子逢森四月夭亡（年十八）——"**芸仅一子，不得延其嗣续耶！**"琢堂赠其一妾，"重入春梦"。

#### 卷四 浪游记快

游幕三十年行迹，"天下所未到者，蜀中、黔中与滇南耳"。开卷即立审美主张：

> "余凡事喜独出己见，不屑随人是非……**名胜所在，贵乎心得，有名胜而不觉其佳者，有非名胜而自以为妙者。**"

| 地点       | 要目                                             |
| -------- | ---------------------------------------------- |
| 山阴吼山     | 十五岁首次快游；水园、"观鱼跃"                               |
| 杭州西湖     | 以龙井为最、小有天园次之；苏小墓；紫云洞登朝阳台，"**此生平第一大观也**"；水乐洞    |
| 扬州平山堂    | 详评虹桥、长堤春柳、小金山、莲花桥（"四盘一暖锅"）、五云多处；称其"奇思幻想，点缀天然"  |
| 海宁安澜园    | "**余所历平地之假石园亭，此为第一**"；钱塘观潮"如万丈银堤破海而过"；尖山"海阔天空" |
| 徽州绩溪     | 富春江、子陵钓台、石镜山、火云洞天、仁里花果会                        |
| **岭南广州** | 花艇"打水围"；沙面、军工厂、潮帮、扬帮；与喜儿往来四阅月；海珠寺、十三洋行、花地      |
| 西山       | 来鹤庵、桂轩、**无隐禅院飞云阁**；星灿弹《梅花三弄》，忆香吹铁笛             |
| 虞山剑门     | 猿攀而上，土人叹"壮哉！游兴之豪，未见有如君者"                       |
| 崇明永泰沙    | "牛背狂歌，沙头醉舞……**真生平无拘之快游也**"                     |
| 苏州诸山     | 贬狮子林"**竟同乱堆煤渣**"；邓尉"香雪海"、"清、奇、古、怪"四古柏          |
| 楚蜀道中     | 皖城大观亭、武昌黄鹤楼冒雪登（"名利之心至此一冷"）、黄州赤壁、荆州刘氏废园"紫藤红树山房" |
| 潼关       | 琢堂为其斋题"**不系之舟**"，"此余幕游以来第一好居室也"；华阴庙、华山玉泉院      |
| 济南       | 大明湖；趵突泉"**凡泉皆从上而下，此独从下而上，亦一奇也**"               |

**岭南一段的特殊分量**：喜儿"身材状貌有类余妇芸娘"，沈复月下顾之，叹"惜余妇芸娘不能偕游至此"。篇末自嘲——

> "**半年一觉扬帮梦，赢得花船薄幸名**"

同时又以相当篇幅记录喜儿、翠姑的身世与"迎新送旧之苦"（"心不欢必强笑，酒不胜必强饮"），超出一般狎游文字，带有人道主义的同情。

#### 卷五、卷六（原缺）

卷五《中山记历》据考为嘉庆十三年（1808）随使团出使**琉球**（中山）的见闻——即本书写作的触发场景。卷六《养生记道》内容不明。二卷均仅有存目，今传"足本"后二记为伪作。

## 四、人物谱

| 人物            | 身份      | 要点                                        |
| ------------- | ------- | ----------------------------------------- |

| **陈芸**（淑珍）    | 妻       | 全书中心。聪慧、有才、有情趣而不容于礼法；1803 年卒              |

| 母             | —       | 有义女九人；对芸由"爱其柔和"到疑忌                        |

## 五、主题与思想

#### 1. 真情与礼法的冲突（核心悲剧）

沈复夫妇之祸，根源&#x4E8E;**"不容于封建大家庭"**。  
芸的每一次"越界"——代笔家书、受托物色姚氏女、主动为夫纳妾、与妓结盟、私游太湖、女扮男装——单独看都是才情与真性，合起来则构成"不守闺训"的证据。沈复点明关键："**多情重诺，爽直不羁，转因之为累。**"
 
值得注意的是书中呈现的**父权结构**：父轻信流言即可逐媳，弟借债而嫂获罪，母之疑忌足以致命。  
而沈复的反应始终是顺从与自责，从不正面反抗——这既是他的软弱，也是那个时代读书人的真实处境。

#### 2. 生活美学：贫士的美学

卷二是全书最有独创性的部分。插花、盆景、叠石、焚香、活花屏、梅花盒、荷花茶——全部建立在"**贫士起居服食以及器皿房舍，宜省俭而雅洁**"的前提上。这套美学的精髓不是花钱，而是**心思**：用馄饨担解决野外热饮，用旧竹帘代替栏杆，用白纸糊墙取亮。

#### 3. 布衣菜饭：非主流的人生理想

芸的卜居之愿——"买绕屋菜园十亩……君画我绣……**布衣菜饭，可乐终身，不必作远游计**"——是全书的价值宣言。  
沈复夫妇"不迷恋功名，不贪图荣华"，与当时读书人的主流取向背道而驰，也正因为如此，他们的一生在经济上始终是失败的。

#### 4. 浪游作为精神出路

卷四的游历不只是记胜，更是沈复在家庭崩解后的精神寄托。他明确说自己的标准不在名胜与否，而在"贵乎心得"。  
贬狮子林为"乱堆煤渣"，褒无名小庵无隐禅院为"妙境"，都体现了**独立于世俗评价的审美自信**。

#### 5. 女性形象的突破

陈芸不是类型化的完美女性。  
沈复写她"两齿微露，似非佳相"，写她的诗"仅有一联，或三四句，多未成篇者"，  
写她为夫纳妾的痴念，写她的迂拘多礼——她是**有缺陷的真实人物**。  
沈复甚至愿"来世卿当作男，我为女子相从"，模糊了性别角色，构成一种亦妻亦友的新型关系。

#### 6. 命运观

全书从"天之厚我可谓至矣"开篇，到"人生坎坷何为乎来哉"转折，再到"绵绵此恨，曷其有极"收束。  
沈复把悲剧归给"命"与"造物之忌"，而非控诉具体的人——这是他的局限，也是那个时代自传文学的诚实之处。

## 六、艺术特色

**一、写实而不虚美。** 作者自定原则为"记其实情实事"。写芸之美，不落"沉鱼落雁"窠臼，而实写"唯两齿微露，似非佳相"；写其才，不写成出口成章的才女，而实写"多未成篇者"。写回煞这类迷信事，也只如实记录所见所闻，无虚妄之词。

**二、自传体的破例之作。** 陈寅恪指出：中国文学"自来以礼法顾忌之故，不敢多言男女间关系，而于正式男女关系如夫妇者，尤少涉及。盖闺房燕昵之情意，家庭米盐之琐屑，大抵不列于篇章"——而《闺房记乐》正是例外。

**三、板块结构 + 互见法。** 各卷主题分明而互见互补，叙事"形散而神不散"。

**四、语言清新真率。** "无雕琢藻饰痕迹"。俞平伯的评语最为精到：

> 此《记》所录所载，妙肖不足奇，**奇在全不着力而得妙肖**；韶秀不足异，异在韶秀以外竟似无物。俨如一块纯美的水晶，只见明莹，不见衬露明莹的颜色；只见精微，不见制作精微的痕迹。

**五、以细节承载情感。** 全书最动人的力量不从抒情来，而从细节来："昔一粥而聚，今一粥而散"、"我母不归矣"、临终"来世"二字、"当日浑闲事，而今尽可怜"。

## 八、一页速览

> **一句话**：一部清代落魄文人写给自己亡妻的自传，以"情""趣"二字为骨，记录布衣菜饭中的生活美学与一场被礼法碾碎的婚姻。
>
> **四个阅读要点**：
>
> 1. **它是中国文学里的破例**——第一次把"闺房燕昵之情意、家庭米盐之琐屑"正式写进文章（陈寅恪语）。
> 2. **陈芸的可爱在于真实**——有才而不完美，多情而不合礼，沈复连她"两齿微露"都如实写下。
> 3. **悲剧不是性格而是结构**——父权、婆媳、兄弟、经济四重压迫叠加，任何一环松动都可能不致如此。
> 4. **生活美学是其独创贡献**——插花、盆景、叠石、焚香、梅花盒、荷花茶、馄饨担……一套不花钱而靠心思的穷人美学。
>
> **两句最沉的话**：  
> "昔一粥而聚，今一粥而散，若作传奇，可名《吃粥记》矣。"  
> "奉劝世间夫妇，固不可彼此相仇，亦不可过于情笃。语云'恩爱夫妻不到头'，如余者，可作前车之鉴也。"
>
> **一个提醒**：今传"足本"六卷中的卷五《中山记历》、卷六《养生记道》**系民国伪作**，读时应以四卷本为准。
